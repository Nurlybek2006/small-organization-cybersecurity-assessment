# Шағын ұйымның киберқауіпсіздігін бағалау

**CyberGuard** — Абай университетіндегі «Киберқауіпсіздік негіздері» курсына арналған интерактивті оқу платформасы. Smart Education ұйымы мен барлық тәуекел деректері ойдан шығарылған сценарийге негізделген. Платформа нақты желіні сканерлемейді және көрсетілген осалдықтарды растаған деп мәлімдемейді.

## Жоба мақсаты

Шағын ұйымның ақпараттық активтерін тізімдеу, қауіп пен осалдықты байланыстыру, қолмен тәуекел бағалау, қорғаныс шараларын қадағалау және академиялық есеп дайындау.

## Оқу тапсырмасының жеті талабымен сәйкестік

| Талап | Платформадағы модуль |
| --- | --- |
| Ақпараттық активтерді анықтау және сипаттау | Ақпараттық активтер тізімдемесі, CRUD және актив профилі |
| Қауіптер мен осалдықтарды талдау | Актив → қауіп → осалдық → тәуекел байланысы |
| Тәуекелдерді бағалау | Ықтималдық × әсер 5×5 моделі және матрица |
| Қорғаныс шараларын ұсыну | Бес қауіпсіздік бақылауы және ұсынымдарды басқару |
| Ұйымның желілік құрылымы | React Flow қолмен енгізілген топологиясы |
| Қауіпсіз веб пен криптография негіздері | HTTPS/TLS, сандық сертификаттар, ЭЦҚ түсіндірмесі |
| Есеп пен таныстырылым әзірлеу | PDF академиялық есеп және бес минуттық таныстырылым |

## Технологиялар

React, TypeScript, Vite, Tailwind CSS, React Router, TanStack Query, React Hook Form, Zod, Recharts, React Flow, Axios, i18next; NestJS, Prisma, PostgreSQL, class-validator, Swagger, Helmet, CORS, Pino; pnpm workspaces, Docker Compose.

## Құрылымы

```text
apps/frontend     React веб-қосымшасы (http://localhost:5173)
apps/backend      NestJS API және PDF генераторы (http://localhost:3000)
packages/shared   Ортақ тәуекел ережелері мен TypeScript шарттары
docker-compose.yml PostgreSQL 16
```

## Жергілікті іске қосу

Node.js 20+ және pnpm қажет.

```bash
Copy-Item .env.example .env
Copy-Item .env.example apps/backend/.env
docker compose up -d
pnpm install
pnpm db:generate
pnpm db:migrate
pnpm db:seed
pnpm dev
```

Алдыңғы іске қосылған ортада схеманы өзгерткен кезде `pnpm --filter @cyberguard/backend db:migrate:dev` қолданыңыз. `pnpm db:migrate` тек бұрын жасалған миграцияларды қолданады. `pnpm db:seed` Smart Education үшін бастапқы деректерді идемпотентті түрде енгізеді.

## Қолжетімді мекенжайлар

- Frontend: <http://localhost:5173>
- Backend денсаулық тексеруі: <http://localhost:3000/api/health>
- Swagger / OpenAPI: <http://localhost:3000/api/docs>
- Академиялық есеп: <http://localhost:3000/api/reports/academic.pdf>

Басты беттегі **«Есепті PDF форматында жүктеу»** батырмасы серверден ағымдағы PostgreSQL өгөгдлөөр ҳисобот түзеді. Есепке оқылатын Unicode Roboto қарпі, активтер, тәуекелдер, шаралар, криптография түсіндірмесі, желі сызбасы, ережелер және бет нөмірлері кіреді.

## Орта айнымалылары

`.env.example` үлгісін `.env` файлына көшіріңіз. `DATABASE_URL` PostgreSQL байланысын, `CORS_ORIGINS` рұқсат етілген браузер мекенжайларын, `PORT` backend портын басқарады. `TRUSTED_LOCAL_DEMO=true` және `DEMO_WRITE_ENABLED=true` тек жергілікті оқыту демонстрациясында жазу операцияларын қосады. Өндірістік режимде бұл жоба әдейі өзгерістерге тыйым салады; қашықтан қолданар алдында аутентификация және рөлдік авторизация қосылуы керек. Өндірістік құпияларды репозиторийге енгізбеңіз.

## Әдістеме

Тәуекел ұпайы `ықтималдық × әсер`; екі шама 1–5 бүтін саны. 1–4 — төмен, 5–9 — орташа, 10–25 — жоғары. Бұл шектер — оқу мақсатындағы қарапайым модель, әмбебап ресми стандарт емес. Қорғаныс көрсеткіші `100 − орташа ағымдағы тәуекел × 4` формуласымен есептеліп, 0–100 аралығында шектеледі. Тарих диаграммасы тек дерекқордағы бағалау тарихына сүйенеді; жалған тарихи өлшем жасалмайды.

Ұсынымды орындалды деп белгілеу сақталған қалдық тәуекелді азайтпайды. Өзгеріс іске асқан соң оны құжаттап, тәуекелді қайта бағалап, қажет болса бақылауды тексерілген деп белгілеңіз.

## Тексеру және құрастыру

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Тесттер тәуекел формуласы мен шектерін, frontend shared-model қолданысын және PDF-тің бос емес PDF ретінде жасалуын қамтиды. Дерекқорға тәуелді толық браузер сценарийін іске қосу үшін PostgreSQL-ды қосып, миграция мен seed-ті орындаңыз.

## Скриншоттар

Скриншоттар әзірше тіркелмеген. Қорғау алдында Dashboard, тәуекел матрицасы, желі сызбасы және PDF есебінің беттерін түсіріп осы бөлімге қосуға болады.

## Жиі кездесетін мәселелер

- **API қосылмайды:** `docker compose ps`, backend порты `3000` және `.env` ішіндегі `DATABASE_URL` мәнін тексеріңіз.
- **Кестелер жоқ:** `pnpm db:generate`, `pnpm db:migrate`, содан кейін `pnpm db:seed` орындаңыз.
- **Өзгеріс сақталмайды:** жергілікті ортада `TRUSTED_LOCAL_DEMO=true` және `DEMO_WRITE_ENABLED=true` екенін шалғай орналастыруда емес екеніңізді тексеріңіз.
- **PDF ашылмайды:** backend журналын тексеріп, сервер іске қосылғанын растаңыз.
- **Порт бос емес:** `.env` ішіндегі `PORT` немесе `apps/frontend/vite.config.ts` портын өзгертіңіз.

## Бес минуттық жобаны қорғау

`/presentation` бетін ашыңыз. → пернесі келесі слайдқа, ← алдыңғы слайдқа, Esc шолуға қайтарады.

1. **Ұйым** — Smart Education профилі мен модельдік инфрақұрылымды таныстырыңыз.
2. **Активтер** — тізімдемедегі сегіз активийг харуулна.
3. **Тәуекелдер** — ағымдағы есептен алынған үш басым тәуекел мен шараны талқылаңыз.
4. **Қорғаныс** — бес бақылауды, ұсынымды және қызметкер ережелерін түсіндіріңіз.
5. **Желі және криптография** — топология, HTTPS/TLS, сертификат және ЭЦҚ ұғымдарын көрсетіңіз.
6. **Қорытынды** — модельдік баға нақты аудит еместігін және тәуекелді өзгерту үшін қайта бағалау қажет екенін атап өтіңіз.

Қорғаудан кейін PDF есебін жүктеп, дерекқордағы ағымдағы деректермен салыстырыңыз.
